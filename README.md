> ### [Análise de Dados com Python](https://github.com/teles-hub/Analise-de-Dados-com-Python)
>
> ![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![Colab](https://img.shields.io/badge/Colab-notebook-F9AB00?style=flat-square)
>
> Análise exploratória de notas e votos de animes da Crunchyroll. Entre os resultados registrados no notebook: **1.235 de 1.255** títulos com pelo menos um voto; nota média **4,15** e mediana **4,36** entre esses títulos.
>
> **Tecnologias:** Python · Pandas · Matplotlib · Seaborn · kagglehub · Colab.
>
> **Situação:** projeto individual, executável no Google Colab; Claude foi usado apenas como apoio de revisão, não como autor.
>
> **Limitações:** números extraídos das saídas salvas; o notebook não foi reexecutado nesta revisão.

> ### [Projeto Hermes](https://github.com/teles-hub/Proposta-Pi)
>
> ![Java](https://img.shields.io/badge/Java-007396?style=flat-square&logo=openjdk&logoColor=white) ![Status](https://img.shields.io/badge/Status-Acad%C3%AAmico-4DA6FF?style=flat-square)
>
> Projeto Integrador de ADS: sistema de vendas em Java (console) com estoque, carrinho, cálculo de tributos e persistência em arquivos. A interface web é uma demonstração separada.
>
> **Tecnologias:** Java · HTML5 · CSS3 · JavaScript (demonstração web) · Python (teste de regressão).
>
> **Situação:** projeto acadêmico encerrado, com teste automatizado em `tests/`.
>
> **Créditos:** Cauê Teles (aplicação Java); Gabriel Roque (interface web); Yuri Vasconcellos e Murilo H. P. (pesquisa de mercado e alíquotas); orientação do Prof. Marcus Gália.
